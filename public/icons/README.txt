Desi Mahol app icons
=====================

icon.svg is a placeholder mark used for the PWA manifest so the app is
installable out of the box. Replace it with real branded artwork before
shipping to production, and export the following raster sizes:

  icon-192.png  — 192x192
  icon-512.png  — 512x512

Then update public/manifest.webmanifest to point at the new files.
